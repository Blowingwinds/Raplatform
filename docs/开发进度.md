## 当前架构决定

### 决定 1：平台负责治理，Agent 负责具体能力

Agent 自己实现其工具调用和领域逻辑；平台负责任务契约、能力匹配、授权范围、MCP 调用、租约、审计和结果归一化。

### 决定 2：黑板保存规范化事实，证据保存原始结果

黑板面向编排和协同，Evidence 面向审计和复核。二者通过 `evidence_ref`、`session_id` 和 `task_id` 关联。

### 决定 3：先 Mock，后真实 Agent

第一版先通过 Mock Planner、Mock MCP Transport 和 Mock Agent 验证数据流与状态机。真实云端模型和真实 Agent 只替换适配器，不改变核心契约。

### 决定 4：第一条演示链路聚焦信息搜集

首个闭环只覆盖资产、端口、服务、网络关系和证据引用，不扩展到高风险利用、持久化或权限维持。
